# 합류신호 알림 (Confluence Signal V3)

안드로이드 타블렛이 매일 미국장 마감 뒤에 관찰 종목을 확인하고,
V3 매수 신호가 나오면 **텔레그램으로 핸드폰에 보내는** 앱입니다.

PC 를 켜 둘 필요가 없습니다. 타블렛만 켜져 있으면 됩니다.

---

## 1. APK 받기 (처음 한 번, 그리고 코드를 고칠 때마다)

이 저장소를 GitHub 에 올리면 **자동으로 APK 가 만들어집니다.**
PC 에 Android Studio 를 깔 필요가 없습니다.

1. GitHub 에서 새 저장소를 만듭니다 (public 로).
2. 이 폴더의 **모든 파일**을 올립니다.
3. 저장소 위쪽 **Actions** 탭 → 방금 돈 빌드를 누릅니다.
4. 초록색 체크가 뜨면 아래 **Artifacts** 의 `합류신호알림-APK` 를 내려받습니다.
   (10~20분 걸립니다. 파이썬 패키지를 받아 넣기 때문에 첫 빌드가 가장 오래 걸립니다.)
5. 압축을 풀면 `app-release.apk` 가 나옵니다.

## 2. 타블렛에 설치

1. APK 파일을 타블렛으로 옮깁니다 (카카오톡 나에게 보내기, 구글드라이브, USB 아무거나).
2. 파일을 눌러 설치합니다.
   "출처를 알 수 없는 앱" 경고가 나오면 **설정 → 허용** 을 눌러 주세요.
   이 앱은 스토어에 올린 게 아니라 직접 만든 것이라 그렇습니다.

## 3. 타블렛 설정 — 이걸 해야 새벽에 안 죽습니다

**① 배터리 보호를 켜세요.**
설정 → 배터리 → **배터리 보호**(85% 제한).
24시간 충전 상태로 두면 배터리가 부풉니다. 서버로 쓸 기기라면 필수입니다.

**② 이 앱을 절전에서 빼세요.**
설정 → 배터리 → 백그라운드 사용 제한 → **절전 안 함 앱** 에 이 앱을 추가.

**③ 화면 꺼져도 와이파이를 끊지 않게 하세요.**
설정 → 연결 → Wi‑Fi → 고급 → 절전 관련 항목을 끕니다.

**④ 알림을 허용하세요.** 앱을 처음 열면 물어봅니다.

## 4. 앱에서 설정하기

앱을 열면 전부 화면에서 고칠 수 있습니다. 파일을 만질 일이 없습니다.

| 항목 | 설명 |
|---|---|
| 관찰 종목 | 쉼표·띄어쓰기·줄바꿈 아무거나. 소문자도 됩니다 |
| 시장 국면 판정 지수 | 기본 `RSP`. 바꾸지 않아도 됩니다 |
| 봇토큰 / 채팅ID | 텔레그램 봇 정보. **이 기기에만 저장됩니다** |
| 신호 없는 날도 알림 | 조용하면 불안할 때 켜세요 |
| 한 메시지 최대 종목 수 | 기본 20 |

**텔레그램 봇 만들기** (이미 쓰고 계시면 그 값을 그대로 넣으세요)

1. 텔레그램에서 `@BotFather` 검색 → `/newbot`
2. 이름과 아이디(`~bot` 으로 끝나야 함)를 정하면 토큰을 줍니다
3. 만든 봇에게 아무 말이나 한 번 보냅니다 (안 하면 봇이 나에게 못 보냅니다)
4. 채팅ID 는 기존 PC 설정의 `텔레그램설정.txt` 에 있는 값과 같습니다

설정을 넣고 **설정 저장** → **텔레그램 시험** 을 눌러 메시지가 오면 성공입니다.
그다음 **지금 실행** 을 한 번 눌러 첫 데이터를 받습니다 (종목 수에 따라 3~10분).

> 첫 실행에서는 과거 신호를 보내지 않습니다. 그날을 기준일로 박아두고
> 과거 신호는 기록만 합니다. 다음 실행부터 새 신호만 옵니다.

마지막으로 **자동 실행** 을 체크하면 끝입니다.

## 5. 언제 도는가

4시간마다 깨어나서 **지금 돌아야 하는지 스스로 판단**합니다.

- 한국시간 07시 이후 (미국장은 새벽 5~6시에 닫힙니다)
- 화~토 (일·월은 새로 닫힌 미국장이 없습니다)
- 오늘 이미 성공했으면 다시 돌지 않습니다

정각을 고집하지 않는 이유는 안드로이드가 절전 때문에 예약 시각을 그대로
지켜 주지 않기 때문입니다. 한 번 놓쳐도 다음 깨어남이 알아서 채웁니다.
타블렛이 꺼져 있었어도 신호를 잃지 않습니다 — 다음 실행이 최근 10거래일을 훑습니다.

## 6. 종목을 바꾸려면

앱에서 고치고 **설정 저장** 하면 끝입니다.

- **넣으면**: 그 종목의 과거 이력을 통째로 받습니다(그 회차만 오래 걸림).
  옛 신호가 쏟아지지 않도록 최근 10거래일 안의 신호만 보냅니다.
- **빼면**: 알림도 데이터도 즉시 멈춥니다. 쌓인 로그는 남습니다.

## 7. 문제가 생기면

앱 화면의 **실행 기록** 버튼을 누르면 로그가 보입니다.

| 로그에 이렇게 나오면 | 원인 |
|---|---|
| `HTTP 401` | 봇토큰이 틀렸습니다 |
| `HTTP 400 chat not found` | 채팅ID 가 틀렸거나 봇에게 먼저 말을 안 걸었습니다 |
| `[건너뜀] XXXX - 404` | 없는 티커이거나 상장폐지된 종목입니다 |
| `[주의] 아직 빠진 봉이 있습니다` | 야후가 아직 그 봉을 안 주는 것. 다음 실행에 다시 시도합니다 |

전송에 실패한 신호는 `대기` 로 남아 **다음 실행 때 다시 보냅니다.** 놓치지 않습니다.

## 8. 구조

```
app/src/main/python/
  yahoo.py           야후에서 일봉을 받아온다 (yfinance 대체)
  watch_download.py  이어받기·빠진 봉 수복·포기 목록      ← PC 판과 거의 같음
  watch_scan.py      V3 신호 판정·텔레그램 전송·로그      ← PC 판과 거의 같음
  app_main.py        앱이 부르는 진입점. 설정 파일을 만들어 준다
app/src/main/java/... 코틀린 껍데기 (화면·예약·전경서비스)
```

**판정 로직은 PC 판과 같습니다.** 검증된 코드를 그대로 옮겼습니다.
바뀐 것은 야후에서 받아오는 부분뿐인데, 그것도 162종목 20만 행을
yfinance 와 대조해 시가·고가·저가·종가·거래량이 **오차 0** 으로 일치함을 확인했습니다.

### 왜 yfinance 를 안 쓰나

최신 yfinance 는 `curl_cffi` 를 필수로 끌어옵니다. C 컴파일이 필요한 물건이라
안드로이드용이 없습니다. 그래서 야후의 차트 엔드포인트만 직접 부르는
`yahoo.py` 를 만들어 그 자리에 끼웠습니다. 표준 라이브러리와 pandas 만 씁니다.

## 9. 알아둘 것

- 이 로그는 **V3 검증 표본이 아닙니다.** 내가 고른 종목이라 이미 편향돼 있습니다.
  검증용 전진 기록은 PC 의 주간스캔 쪽입니다. 섞지 마세요.
- 신호는 "무엇을 살까"보다 **"지금이 살 때인가"**에 가깝습니다.
  국면이 켬일 때만 검증에서 우위가 있었습니다(끔 구간은 −0.1%p, 귀무 39%).
- `keystore/app.jks` 는 앱 서명용입니다. 매번 같은 열쇠로 서명해야
  **기존 앱 위에 덮어 설치**가 됩니다. 지우거나 바꾸지 마세요.
